# DeployerX v0.1.4

DeployerX 0.1.4 expands the project from an SSH deployment helper into a broader Windows infrastructure operations workspace. This release adds dedicated uptime, backup, database, VNC, and local AI integration modules while keeping local/offline operation as the default path.

## Highlights

### Uptime Monitor

- HTTP/API, TCP, and TLS monitoring.
- Scheduled background worker with persisted state and bounded concurrency.
- Incident thresholds, acknowledgement, escalation, recovery, and maintenance windows.
- Shared desktop, email, webhook, Slack, and Microsoft Teams notifications.
- Coverage-aware availability, latency, daily trend, CSV, and PDF reporting.

### Backup Manager

- Manual and scheduled local or SSH/SFTP file backups.
- Encrypted local, SFTP, and S3-compatible repositories.
- Snapshot browsing, retention, pruning, verification, audit evidence, and guided recovery.
- Core database workflows for MySQL, MariaDB, PostgreSQL, Supabase PostgreSQL, SQLite, MongoDB, Redis, and ClickHouse within the documented compatibility boundaries.

### Database Manager and Tabularis

- Top-level Database Manager navigation now downloads and launches the reviewed Tabularis `0.18.0` Windows x64 portable release.
- The official asset is pinned by version, filename, byte size, and SHA-256 digest before it is cached or executed.
- The repository includes an in-progress native DeployerX database foundation for PostgreSQL, MySQL/MariaDB, and SQLite profiles, queries, schema tools, notebooks, exports, tasks, logs, drivers, and Backup Manager connection sharing.
- The native module is not the primary Database Manager navigation path in v0.1.4.

### Server Operations

- Refreshed overview, navigation, workspace, settings, and theme experience.
- Embedded Windows VNC sessions alongside SSH and SFTP.
- Improved server grouping, activity, templates, import/export, and emergency-stop workflows.
- More resilient GitHub update checks and manual-release fallback behavior.

### DeployerX MCP

- Local Streamable HTTP MCP endpoint with bearer authentication.
- Saved-server discovery through opaque IDs.
- Bounded SSH command execution and SFTP list/read/write/mkdir/move/delete tools.
- Loopback-only default binding and internal credential resolution.

## Security and Reliability

- Sensitive Uptime headers and shared credentials use encrypted secret references.
- Backup repositories authenticate encrypted content and retain operational audit evidence.
- Database driver and plugin operations use constrained process and IPC boundaries.
- Firestore rules and cloud-safe projections have been expanded for new shared metadata.
- Third-party notices and dependency license texts are included in the source tree.

## Install

This release currently provides GitHub-generated source archives. No Windows installer or portable executable is attached because a signed release artifact was not available at publication time.

To run from source on Windows:

```powershell
git clone https://github.com/me-devms/DeployerX.git
cd DeployerX
git checkout v0.1.4
npm install
npm start
```

## Important Notes

- This is an early public release. Test with non-production systems and data first.
- Backup support is limited to the exact engines, versions, tools, privileges, topologies, repositories, and restore paths in the [core compatibility matrix](https://github.com/me-devms/DeployerX/blob/v0.1.4/documentation/backup-manager/CORE_COMPATIBILITY_MATRIX.md).
- Database Manager still has pending real packaged-Windows, live-driver/plugin, tunnel, multi-device, and assistive-technology acceptance work.
- Uptime Monitor still has pending packaged Windows and visual acceptance work.
- Always verify backups through a controlled restore drill.
