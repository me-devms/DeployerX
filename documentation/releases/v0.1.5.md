# DeployerX v0.1.5

DeployerX 0.1.5 focuses on connected-server reliability, embedded VNC, secure database access, MCP automation, and Uptime operations. It also includes the UI and lifecycle fixes completed since v0.1.4.

## Highlights

### Database Access Manager

- Connected PostgreSQL, MySQL/MariaDB, and SQLite profiles can open in the bundled DeployerX DB Access Manager workspace.
- Connection handoff uses a randomized, bounded Windows named pipe and an ephemeral payload.
- Database secrets are kept out of renderer IPC, process arguments, environment variables, logs, and temporary handoff files.
- Read-only profile restrictions are enforced in the companion backend.
- Packaging preparation, validation, license inventory, and third-party notices cover the adapted Apache-2.0 Tabularis workspace.

### Embedded VNC

- Added an embedded noVNC-based client for Windows hosts running a compatible VNC server.
- Added endpoint diagnostics and clearer timeout, authentication, and transport errors.
- Preserved VNC state while navigating between server views until the user explicitly disconnects.
- Fixed full-screen layout collapse, transition timing, scaling, and blank-frame repaint behavior.
- Added focused layout, lifecycle, persistence, and Electron full-screen regression tests.

### DeployerX MCP

- Added real-time server metrics alongside the existing saved-server, SSH, and SFTP tools.
- Added Uptime Monitor tools for status, monitor CRUD, test and run-now actions, checks, incidents, maintenance windows, worker state, settings, and reports.
- Enabled MCP integrations now restore automatically when DeployerX starts.
- Added health monitoring, bounded restart handling, token rotation recovery, and stronger connection testing.
- The endpoint remains loopback-only by default and requires bearer authentication.

### Server and UI Reliability

- Improved centralized SSH state and server-selection behavior across terminal and monitoring views.
- Refined Add Server credentials, password controls, VNC/RDP fields, responsive modal sizing, search, and multiple-user workflows.
- Corrected connection-state indicators and dashboard data visibility for disconnected servers.
- Improved title capitalization, navigation visibility, theme styling, and several dense form layouts.

### Backup and Uptime

- Manual-only backup jobs no longer require schedule timezone fields.
- Improved Backup Job protection layout and source/recovery validation behavior.
- Strengthened Uptime check execution, scheduled-worker startup, restart behavior, and integration coverage.

## Install

This release provides GitHub-generated source archives. No Windows installer or portable executable is attached because an approved prebuilt artifact was not available, and no release build was produced as part of this publication.

To run from source on Windows:

```powershell
git clone https://github.com/me-devms/DeployerX.git
cd DeployerX
git checkout v0.1.5
npm install
npm start
```

## Important Notes

- This is an early public release. Test with non-production systems and data first.
- Always verify backups through a controlled restore drill.
- VNC requires a compatible server on the remote host and appropriate firewall access, normally on port `5900`.
- The local DeployerX DB Manager submodule contains development work outside the parent release commit; the v0.1.5 source release publishes the DeployerX parent repository state and its recorded submodule revision.
- Database Manager and Uptime Monitor still have pending packaged-Windows and broader live-environment acceptance work.
