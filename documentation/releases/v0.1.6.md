# DeployerX v0.1.6

DeployerX 0.1.6 improves terminal navigation, server workflows, and visual consistency across every bundled theme.

## Highlights

### Terminal Navigation

- Added an SSH action to the top navigation that opens the active, connected, favorite, or first available SSH server.
- Terminal tabs now use a continuous sequence after tabs are closed.
- Terminal labels include the connected username so multiple sessions are easier to identify.
- Improved terminal and SFTP session state coverage.

### Theme and UI Reliability

- Reworked form controls, dashboard rows, operation surfaces, and status elements to follow the active theme.
- Removed remaining bright white surfaces from dark themes.
- Corrected Catppuccin primary-button contrast while preserving white text on destructive actions.
- Fixed server toolbar and action-button overlap during scrolling.
- Refined server search and SFTP path controls for consistent sizing, spacing, and alignment.
- Preserved the original casing of file and directory names in browser rows.

## Windows Downloads

- `DeployerX-0.1.6-Setup-x64.exe` installs DeployerX on Windows.
- `DeployerX-0.1.6-Portable-x64.exe` runs DeployerX directly without installation.

The DeployerX DB Access Manager payload is intentionally excluded from both Windows artifacts in this release.

## Important Notes

- This is an early public release. Test with non-production systems and data first.
- Always verify backups through a controlled restore drill.
- The Windows artifacts are unsigned, so Windows may display a SmartScreen warning.
