Documentation

Connect an AI client

The desktop app must remain open while an agent uses this MCP endpoint.

  1. Start MCP.Choose a free local port, then copy the generated URL and bearer token.
  2. Add the HTTP server.Use Streamable HTTP and send Authorization: Bearer <token> with every request.
  3. Verify access.Ask the client to list DeployerX servers before running a command or changing files.
Codex configuration

Put the token in DEPLOYERX_MCP_TOKEN, then add this to your Codex config.toml.

[mcp_servers.deployerx]
url = "http://127.0.0.1:43821/mcp"
bearer_token_env_var = "DEPLOYERX_MCP_TOKEN"
default_tools_approval_mode = "prompt"
tool_timeout_sec = 300
Generic MCP client

Clients that accept JSON server definitions can use an HTTP entry with an authorization header.

{
  "mcpServers": {
    "deployerx": {
      "type": "http",
      "url": "http://127.0.0.1:43821/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
Hosted chats and remote agents

127.0.0.1 is reachable only from this computer. Codex app, CLI, and IDE can share the local configuration above. Codex cloud and ChatGPT web do not read this machine's localhost configuration; hosted ChatGPT Work receives remote MCP tools through plugins. A different remote agent can connect only if it supports Streamable HTTP and has a trusted HTTPS tunnel or private route to this endpoint. A tunnel makes the URL reachable, but does not install it into a hosted chat. Never expose the port directly to the public internet.

Available tools

deployerx_ssh_executeRuns a non-interactive SSH command with timeout and bounded output.
deployerx_sftp_listLists a remote directory.
deployerx_sftp_readReads UTF-8 or base64 files up to 2 MiB.
deployerx_sftp_writeCreates or replaces UTF-8 or base64 files up to 2 MiB.
deployerx_sftp_mkdirCreates remote directories.
deployerx_sftp_moveRenames or moves remote items.
deployerx_sftp_deleteDeletes files or explicitly recursive directories.
Protocol and security behavior

DeployerX serves stateless MCP over Streamable HTTP and requires bearer authentication before parsing a request. It listens only on 127.0.0.1, limits request and tool payload sizes, redacts connection targets from transport errors, and resolves credentials internally from the selected server ID. SFTP is the SSH File Transfer Protocol; insecure plain FTP is intentionally not exposed.
